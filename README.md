# Locks by Lona

Editable source for the [Locks by Lona website concept](https://locks-by-lona.higgsfield.app/). This is a sample, not Alona Swayne's official website.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.

Run `npm run build` to create the production files in `dist/`. The Vite base path is `/Lona/` for this GitHub repository; change `base` in `vite.config.js` if hosting elsewhere.

Booking opens Tribe & True Salon on Vagaro; visitors must choose Alona Swayne as the stylist. Portfolio photos are from [@locks.by.lona](https://www.instagram.com/locks.by.lona/) and each photo links to its original post. Obtain Alona's approval before using this as her official site or publishing the photos under a new domain. The sample asks search engines not to index it.
